# Full-stack-course
A full-stack learning repository documenting my Flutter journey, covering UI fundamentals, widgets, state management, and beginner applications like Counter and Todo List.

# Flutter Frontend Learning Repository

This repository documents my journey of learning Flutter as part of my full-stack development course. It includes hands-on practice with Flutter fundamentals, widget-based UI development, and state management concepts.

## Topics Covered

* Flutter project structure
* Dart programming basics
* Stateless and Stateful Widgets
* Widget tree and UI composition
* Layout widgets (Row, Column, Container, Stack, etc.)
* Navigation basics
* User input and forms
* State management using `setState()`
* Material Design components

## Projects Included

* Counter App
* Todo List App
* Basic UI practice applications
* Small interactive Flutter exercises

## Purpose

The goal of this repository is to build a strong foundation in Flutter development by implementing concepts through practical mini-projects. As I continue learning, more intermediate and advanced Flutter applications will be added to this repository.

**Tech Stack:** Flutter • Dart • Android Studio • Material Design
